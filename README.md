# rusty-bargain-car-price
Modelo de regresión para predecir el valor de mercado de autos usados. Comparación de LightGBM, CatBoost y XGBoost evaluando la calidad predictiva frente a la velocidad de entrenamiento. (Esta descripción es ideal porque incluye las palabras clave: regresión, LightGBM, CatBoost, XGBoost y velocidad).
